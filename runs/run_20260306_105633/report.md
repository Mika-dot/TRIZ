# Полный отчёт по ТРИЗ-пайплайну

## Входная задача

В серверном шкафу корпоративной сети перегревается коммутатор верхнего уровня. Добавлять отдельный кондиционер или активное охлаждение нельзя. Нужно снизить температуру оборудования и сохранить стабильность работы сети.

## Ограничения

Нельзя увеличивать энергопотребление. Нельзя менять габариты шкафа. Нельзя снижать отказоустойчивость сети. Желательно использовать уже имеющиеся ресурсы внутри шкафа или надсистемы.
